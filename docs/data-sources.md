# 数据源与能力矩阵

本文说明 Limpid 演示站每个页面背后的数据从哪里来、是否可用，以及缺失时界面如何表现。

## 一句话总结

本站点**不连接任何真实行情或大模型服务**。价格、K 线与研究报告由固定随机种子的生成脚本产出，可离线复现；港股、A 股、财报、估值与新闻能力在演示环境中不可用，界面上会明确标注原因，而不是留白或编造数值。

## 缺失数据时的界面行为

1. **不填空白**：能力不可用时会说明原因，例如"Longbridge CLI 未安装"，并给出下一步操作。
2. **不用近似值**：财务与估值字段显示 `—`，不会用估算值或历史数据顶替。
3. **不发起无效请求**：页面加载不请求外部接口；"重新载入快照"只读取内置数据并提示当前为静态环境。
4. **来源与时效随数据展示**：行情区域显示数据源名称与快照时间。

## 如何重新生成模拟数据

```bash
node scripts/generate-demo-data.mjs
node scripts/smoke.mjs
```

- 生成器位于 `scripts/lib/demo-market.mjs`（行情）与 `scripts/lib/demo-narrative.mjs`（研究、副驾驶、投资逻辑、提醒、事件）。
- 随机种子固定，同一份代码在任何机器上产出完全相同的数据。
- 所有指标（SMA、EMA、RSI、回撤、区间回报）都由同一条价格序列计算，因此图表、表格与文字里的数字始终一致。
- 冒烟检查会校验研究报告引用的价格与指标是否和快照一致，防止两者再次漂移。

## 接入真实数据时需要改什么

如果后续要接入 Longbridge 或真实模型：

1. 在 `wrangler.jsonc` 中通过 `wrangler secret put` 保存密钥，**不要把密钥写进前端代码**。
2. 新增一个 Worker 路由（例如 `/api/chat`）代理模型请求，并加限流与鉴权。
3. 把 `public/app.js` 与 `public/mobile.js` 中的 `SNAPSHOT_ONLY` 关闭，改回真实请求路径。
4. 同步更新本文档与 README 的数据说明，并在界面上标注真实数据源与延迟状态。
